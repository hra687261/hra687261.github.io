# hra687261.github.io

This repository contains the source code of
[my web page](https://hra687261.github.io/) built using
[Verso](https://verso.lean-lang.org)
(inspired by
[leodemoura.github.com](https://github.com/leodemoura/leodemoura.github.com))

Build with:
```
lake build
```
or:
```
make
```
Deploy locally for testing with:
```
make serve
```
Stop the local server with:
```
make stop
```
